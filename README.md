# Martabak Robby - Self Order App

Aplikasi Self Order berbasis Flutter untuk Martabak Robby. Pelanggan bisa lihat menu, tambah ke keranjang, dan checkout langsung dari aplikasi.

## Fitur

- Menu martabak per kategori (Martabak Manis & Martabak Telur)
- Keranjang belanja (tambah, ubah jumlah, hapus item)
- Konfirmasi pesanan dengan nomor antrian otomatis

## Tech Stack

- Flutter & Dart
- provider (state management)
- intl

## Cara Menjalankan

```bash
git clone https://github.com/aanisya/sistem-self-order-martabak-robby-flutter.git
cd sistem-self-order-martabak-robby-flutter
flutter pub get
flutter run
```

## Platform

Android & Web
